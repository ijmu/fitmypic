How the batch runs

Files are decoded, resized, and re-encoded strictly one at a time, and the same device-memory pixel limits as the single-image tool apply. Intermediate canvases are released after each file. Because output is re-encoded from pixels, exported files never contain EXIF metadata. ZIP archives are stored without extra compression — JPG, PNG, and WebP are already compressed.
