Upload troubleshooting

Why your form rejected your photo

The error message is usually vague. Four checks explain almost every rejection: dimensions, file size, format and aspect ratio.

By FitMyPic EditorialPublished 2026-11-07Last reviewed 2026-11-07How we test

At a glance

  • Read the form's rules first: maximum pixels, maximum KB, accepted formats and required ratio.
  • Dimensions and file bytes are separate checks; passing one does not pass the other.
  • Resize before lowering JPEG quality, and always return to the original before another export.
  • All FitMyPic processing runs in your browser; the photo is not uploaded.

Reason 1: pixel dimensions

Modern phones commonly produce 4000×3000 or larger files. If a form asks for at most 2000×2000, resize to its maximum while keeping the aspect ratio. If it asks for a minimum and your source is smaller, modest upscaling may pass, but it cannot create lost detail.

Open the image resizer and enter the required dimensions. Scale down rather than crop unless the form also requires a particular shape.

Reason 2: file size

A 12 MP phone JPEG can be 4–8 MB while a form may allow 1 MB. Resize first; reducing both width and height by half removes three quarters of the pixels. If the file is still over the cap, export JPEG around quality 75–85 and compare the result.

Do not repeatedly compress the already-compressed copy. Start from the original each time to avoid stacking JPEG artefacts. Open the image compressor.

Reason 3: unsupported format

Forms commonly whitelist JPG, PNG and sometimes GIF. WebP, HEIC, AVIF and TIFF may be valid images but still be rejected. Rename-and-retry does not work: it changes the label, not the encoded bytes. Convert properly—JPG for photographs, PNG for screenshots, documents and transparency.

For the wider WebP compatibility picture, see PNGToolbox's compatibility guide.

Reason 4: aspect ratio

Compute width ÷ height. 3024×4032 is 3:4; 4032×3024 is 4:3; a square requirement means exactly 1:1. Crop a little from the long side when the difference is small. If cropping removes the subject, use padding if the form permits it. Never stretch a face or document to force a ratio.

Open FitMyPic tools to crop, resize and export the final dimensions.

The 60-second pre-submission checklist

  1. Find the stated pixel range, byte cap, accepted formats and ratio.
  2. Check dimensions and resize if needed.
  3. Check bytes; resize, then quality-adjust if needed.
  4. Check the extension and convert if it is not whitelisted.
  5. Check width ÷ height and crop or pad if required.
  6. Re-check the final file once; one fix can push another number over its limit.

FAQ

Can I rename .webp to .jpg?

No. Renaming changes only the filename. Decode and convert the image to create a real JPG.

How small can I make a JPEG?

Quality 75–85 is usually a practical form range. If the result still exceeds the cap, reduce dimensions before crushing quality further.

Why does my phone preview pass but the form rejects it?

Gallery apps may display a re-encoded preview. Check the actual file's dimensions, bytes and format.

Are these tools private?

Yes. Processing happens locally in your browser; files are not uploaded or stored.
