What the preset actually does

The crop option fills the full square without stretching the subject. The fit option preserves the complete image and adds canvas space when the source is not square. FitMyPic always exports a real 1024 × 1024 file and reports the encoded file size.

Choose crop or fit

Use crop for centered portraits, avatars, and product thumbnails. Use fit when text, product edges, or important details sit close to the border. The canvas color is only visible when space is added or when JPG needs an opaque background.

Limits worth checking

Enlarging a source smaller than 1024 pixels cannot restore missing detail. A target KB value is approximate because image detail affects compression, and lossless PNG output cannot be forced to an exact file size by changing quality.

1024 × 1024 image questions

How do I make an image exactly 1024 × 1024?

Choose the image and select crop to fill for a full square, or fit entire image to preserve every edge with added canvas space. Both options export an exact 1024 × 1024 file.

Will resizing to 1024 × 1024 stretch the image?

No. Crop to fill removes content from the longer dimension, while fit preserves the source proportions. Neither option stretches the subject.

Which format should I use?

Use JPG for photos and smaller uploads, PNG for transparency or sharp graphics, and WebP when a modern website accepts it.
